# 现代威科夫量价与流动性操盘体系指南 (Modern Wyckoff & SMC Trading Guide)

本指南将**经典威科夫量价本质（供求与努力结果法则）**与**现代金融微观结构（聪明钱流动性理论 / SMC）**深度融合，摒弃传统繁复主观的阶段猜测（Phase A~E）与模糊打分，采用**客观、可证伪、大道至简的三步实战决策树**。

同时，本体系与 `mcp-aktools` 内置的 `analyze_wyckoff_structure` 和 `stock_volume_profile` 量化诊断工具深度打通。

---

## 一、 底层核心逻辑：供求与现代掠夺性做市

1. **供求与努力结果（Effort vs Result - 威科夫之魂）**：
   - **成交量 = 努力（Effort）**，**K线实体与价差 = 结果（Result）**。
   - **健康配合**：大阳大成交量（量增价涨），回踩极致缩量（地量地价，卖压枯竭）。
   - **量价异动警报**：
     - **长下影 + 巨量**：空头付出巨大努力却打不低价格，机构在低位全面吸收被动止损盘（Stopping Volume）。
     - **放量滞涨**：天量成交却只收微涨小阳或长上影，机构借势对倒派发。
     - **缩量阴跌**：下方无承接买盘，绝对不盲目抄底。

2. **现代微观结构认知（聪明钱对手盘与流动性猎杀）**：
   - 机构大资金建仓无法直接市价扫货（否则造成巨大冲击成本）。
   - 机构必须寻找**散户止损密集的流动性池（Liquidity Pools）**，通过故意击穿关键技术位来触发散户的被动止损单，作为自己的对手盘平价成交。

## 二、 核心实战概念与技术定义

| 现代核心概念 | 对标古典威科夫 | 客观技术定义 | 实战意义 |
| :--- | :--- | :--- | :--- |
| **流动性池 (Liquidity Pool)** | 前期箱体边界 / 浮筹 | 显著的前期波段高点/低点（Swing High/Low）、等高点 (EQH)、等低点 (EQL)。 | 散户止损单密集聚集的“火药库”。 |
| **流动性掠夺 (Liquidity Sweep)** | **Spring (终极震仓)** / **UT (上冲回落)** | 价格盘中击穿关键前低（诱空），但**收盘迅速拉回支撑位上方**，留明显下影线。 | 确认主力完成止损猎杀与筹码收集。 |
| **结构转变 (MSS / CHoCH)** | **SOS (强势出现)** | 发生 Sweep 之后，价格放量**实体收盘突破最近的波段供给高点**。 | 标志短期供求关系彻底逆转，左侧转右侧。 |
| **失衡区 (FVG) / 订单块 (OB)** | **LPS (最后支撑点)** | 突破大阳线所留下的 3 根 K 线不重叠跳空区（Fair Value Gap）。 | 机构未撮合完全的真空区，为最佳回踩上车点。 |
| **筹码分布 (Volume Profile)** | 筹码密集区 / 价值区 | 价格区间的成交量分档累计：控制点 (POC)、70% 价值区 (VAH/VAL)。 | 评估套牢筹码阻力与获利盘比例。 |

## 三、 实战三步决策漏斗 (Three-Step Funnel)

在任何分析与实战交易中，直接执行以下三步，杜绝分析瘫痪：

```
                    【现代威科夫实战三步漏斗】
                     
  [1. 定位置 Where]  价格是否触及显著流动性池 (前低/箱体下轨/极端超跌区)？
         │ (否: 震荡中段，禁止交易，视为噪音)
         ▼ (是: 进入观察)
  [2. 查异动 What]   是否发生流动性掠夺 (Sweep 破位收回) 并触发结构转变 (MSS)？
         │ (否: 仍处于顺势下跌，禁止盲目抄底)
         ▼ (是: 确立反转)
  [3. 扣扳机 When]   缩量回踩失衡区 (FVG / OB) 挂单，止损设在被掠夺最低点，
                     测算上方目标，盈亏比 (R:R) 是否 ≥ 1:2？
```

### Step 1: 定位置（Where）—— 寻找关键流动性区
- 价格必须处于**关键极值边界**（前低、强支撑带、大周期 POC / VAL）。
- **铁律**：严禁在区间中段进行任何猜顶猜底交易。

### Step 2: 查异动（What）—— 确认掠夺与反转
- **看下影（Sweep）**：跌破前低但并未崩盘，反被大单在 1~2 根 K 线内迅速收回。
- **看反包（MSS）**：出现放量大阳线，实体收盘强行吞没上一个波段的下跌起点。未出现 MSS 前一律视为弱反弹。

### Step 3: 扣扳机（When）—— 失衡回踩与硬性风控
- **入场点**：不追高大阳线，等待次日或分时**缩量回踩 FVG（失衡区 50% 处）或突破颈线**。
- **生命线（止损）**：必须**无条件设在被掠夺的波谷最低点下方**。若再度跌破，说明假突破判断失败，坚决止损。
- **盈亏比（R:R）**：上方第一阻力位（上一个前高/流动性池）的空间，必须大于止损空间的 **2 倍以上（$\ge 1:2$）**。

---

## 四、 交易信号评级标准 (Tier 1 ~ Tier 3)

- 🟢 **Tier 1 (高胜率行动)**：Sweep 诱空完成 + MSS 实体突破确认 + 缩量回踩 FVG，盈亏比 $\ge 1:2.5$。
- 🟡 **Tier 2 (观察待确认)**：仅出现 Sweep 探底，尚未突破关键供给高点（MSS 未触发），或缩量震荡中，保持盯盘不追。
- 🔴 **Tier 3 (空头/禁止操作)**：单边下跌破位无承接，或震荡中段无赔率，无任何主力吸收迹象。

## 五、 工具接口使用说明

在 MCP AkTools 中，可通过调用以下工具直接获取结构化数据：

1. **`analyze_wyckoff_structure(symbol, market, period='daily', lookback=90)`**
   - 返回波段高低点流动性池（`structure_and_liquidity`）
   - 量价异动检测（`effort_vs_result.volume_price_anomalies`）
   - 流动性掠夺与结构转变信号（`signals.liquidity_sweep` / `market_structure_shift_mss`）
   - 未回补失衡区（`signals.unmitigated_bullish_fvgs`）
   - 包含硬性止损位、目标位、盈亏比与 Tier 评级的执行计划（`execution_plan`）

2. **`stock_volume_profile(symbol, market, lookback=90, bins=24)`**
   - 计算筹码控制点 POC（主力成交最密集价位）
   - 70% 价值区上下沿（VAH / VAL）
   - 获利盘比例与 90% 筹码集中度
